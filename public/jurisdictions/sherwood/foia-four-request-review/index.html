What Arkansas law requires

Arkansas Code § 25-19-105(a)(3)-(4) requires a written response to a written request stating when responsive records do not exist, identifying applicable exemptions for existing responsive records withheld, or identifying the appropriate custodian when administrative control rests elsewhere, if known or readily ascertainable. Email is permitted. The cited provision does not expressly require an individual-file withholding index or a detailed search narrative. Subsection (f) requires segregable nonexempt portions and an indication of deleted information. Subsection (d)(2) addresses readily available/convertible electronic formats and does not require creation of new records. These rules do not by themselves resolve whether any selected response violated the law.
