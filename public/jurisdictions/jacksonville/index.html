Jacksonville ALPR Audit Evaluation

The review covers Jacksonville's ALPR policy, a June 14–July 14 audit PDF, and an outside-agency participation record. The audit contains 267 distinct IDs; nine searches display scopes over 5,000 networks.

The released PDF shows a visible case value for 98 IDs and no visible value for 169. Because the PDF is flattened and grouped, those figures describe the released document—not a conclusion that 169 searches lacked a case or authorization elsewhere.

Limit. Search scope does not establish which agencies returned results or how any result was used. The audit PDF contains names and operational fields, so only aggregate findings are republished here.
