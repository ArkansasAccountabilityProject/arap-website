## Important pre-deployment check

The paper contains an **Evidence Note** for the Sherwood installation drawing that supplied the 12-foot pole height and 24.8-foot setback.

If the public/redacted installation drawing already exists in the website evidence repository, replace that note with a direct exhibit link before public deployment.

If it is not yet publicly hosted, the present wording is deliberately cautious and can remain until the exhibit is added.

## Scope intentionally excluded

This publication does **not** cover:

- audit-log quality
- after-the-fact auditing
- pre-search approvals
- supervisory authorization
- municipal accountability
- statutory reporting compliance

Those topics are reserved for a separate accountability paper.

## Source policy

Manufacturer specifications are labeled as manufacturer-described claims rather than independently validated measurements.

The 27.6-foot value is a mathematical derivation from project-record dimensions and is explicitly described as a minimum to the pavement edge, not a vehicle distance.

## Accessibility

Both SVG files contain `<title>` and `<desc>` elements and the Markdown image tags contain descriptive alt text.
